# Git & GitHub CLI Documentation Assets

Official offline documentation specifications from GitHub Docs (`https://docs.github.com/en/get-started/using-git`) and GitHub CLI (`gh`).

## Directory Structure

```
assets/
├── using-git/                   # Official Git & Remote Workflow Guides
│   ├── about-git.md             # DVCS principles, repository concepts & DAG
│   ├── about-remote-repositories.md # HTTPS, SSH, and origin remotes
│   ├── getting-changes-from-a-remote-repository.md # git fetch, pull, and clone
│   ├── pushing-commits-to-a-remote-repository.md  # git push, tracking branches
│   ├── managing-remote-repositories.md # git remote add, rename, remove
│   ├── caching-your-github-credentials.md # Git credential helper, GCM, keychain
│   ├── ignoring-files.md        # .gitignore syntax, global excludes
│   └── associating-text-editors-with-git.md # Core editor configuration
│
└── cli/                         # Official GitHub CLI (gh) Reference Manual
    ├── gh-reference.md          # Complete reference manual (2,300+ lines)
    ├── gh-environment.md        # Environment variables (GH_TOKEN, GH_HOST, etc.)
    └── gh-formatting.md         # Template formatting, JSON queries, and flags
```
