# LLM Evaluation Metrics Reference Catalog

1. **Faithfulness**: Measures if the actual output can be inferred purely from the retrieval context (detects hallucinations).
2. **Answer Relevancy**: Assesses whether the output directly addresses the user query.
3. **Context Precision**: Determines whether the most relevant information in the context was ranked at the very top.
4. **Context Recall**: Verifies whether all ground-truth facts needed to answer the query were successfully retrieved.
5. **Hallucination Metric**: Binary or probabilistic score assessing whether factual claims in the output contradict trusted source documents.
