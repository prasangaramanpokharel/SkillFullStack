# GitHub Organization & Team Documentation Assets

Official offline specifications from GitHub Docs (`https://docs.github.com/en/organizations`) covering organizations, team hierarchies, and permission roles.

## Directory Structure

```
assets/
├── organizations/               # Organization Governance & Security
│   ├── about-organizations.md
│   └── repository-roles-for-an-organization.md # Read, Triage, Write, Maintain, Admin
│
├── teams/                       # Team Topologies & Routing
│   ├── about-teams.md
│   └── adding-members-to-a-team.md
│
└── rest-api/                    # REST Endpoints for Teams & Permissions
    ├── teams.md
    ├── orgs.md
    └── collaborators.md
```
